LA County has a race condition in their reporting. The process that writes out the json results file sometimes runs while the database is being updated with candidate totals. When this happens it produces a json results file that has updates for only some candidates - so for the effected contests it will look like one candidate got 100% of the vote. This directory contains the partial drop files for posterity. We have just removed them from the viewer which has the effect of combining this drop's data with the subsequent drop's data.
